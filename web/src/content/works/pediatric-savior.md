A GPT-based rapid-cycle simulator for pediatric airway training, built with Emory Pediatrics and Children's Healthcare of Atlanta.

Residents run cases. Admins edit instructions. The system includes chat, a case editor, conversation history, and Auth0 roles.

The application uses React, Flask, MongoDB, and AWS.
